> Início do acompanhamento: **06/10/2026** (pós-eleição). Primeira checagem sugerida: **abril/2027** (100 dias de governo). Demais checagens: a cada 6 meses.

## Como usar

- Cada item abaixo é um **Indicador de resultado** declarado no plano.
- Marque `[x]` quando houver evidência; preencha `evidência` com a fonte (link de notícia, relatório oficial, dado público) e a data.
- Status sugerido: `a verificar` → `em andamento` → `cumprido` / `parcial` / `não cumprido`.
- Cada alteração vira um commit no git (histórico do acompanhamento).
